# ua_mx

Urban Areas of Mexico

## Usage

``` r
ua_mx
```

## Format

A sf object with 658 rows and 2 variables:

- id:

  the ids.

- geometry:

  geometry column

## Source

<https://dataforgood.facebook.com/dfg/tools/globalurbanareas>

## Details

La base de las area urbana de mexico derivada de la base de las areas
global urbanas de meta data for goof of facebook
